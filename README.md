# SQL Online Store Analysis

## О проекте

Учебный проект по анализу данных интернет-магазина с использованием SQL и SQLite.

Цель проекта — создать реляционную базу данных, заполнить её тестовыми данными и провести анализ продаж, товаров и клиентов.

## Используемые инструменты

- SQL
- SQLite
- GitHub
- Markdown

## Структура базы данных

Проект включает четыре связанные таблицы:

- `customers` — информация о клиентах;
- `products` — каталог товаров;
- `orders` — заказы;
- `order_items` — состав заказов.

## Выполненные задачи

- Создание таблиц и связей между ними.
- Заполнение базы тестовыми данными.
- Объединение таблиц с помощью `JOIN`.
- Фильтрация данных с помощью `WHERE`.
- Группировка и агрегирование с помощью `GROUP BY`, `SUM`, `COUNT`, `AVG`.
- Сортировка результатов с помощью `ORDER BY`.
- Расчёт выручки, среднего чека и продаж по категориям.
- Анализ покупательской активности.
